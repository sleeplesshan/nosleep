Sleeplesshan 0.1.0
macOS 14+ / Apple Silicon (M-series)
https://github.com/sleeplesshan/nosleep

INSTALL
1. Unzip the download and move Sleeplesshan.app to Applications.
2. Open Sleeplesshan.app. Xcode and source compilation are not required.
3. This build is ad-hoc signed, not Developer ID signed or Apple notarized.
   macOS may block first launch. If you choose to trust this release, follow
   Apple's instructions in System Settings > Privacy & Security:
   https://support.apple.com/en-us/102445
4. Allow Accessibility access when you want lock-and-display-off.
   Changing sleep prevention may request macOS administrator authentication.
5. Enable Launch at login inside the app if desired.

UPDATES
Quit the old app before replacing it. Keep the same install location.
Ad-hoc build updates may require re-adding the app in Accessibility settings.

설치
1. ZIP 압축을 풀고 Sleeplesshan.app을 응용 프로그램 폴더로 옮깁니다.
2. 앱을 실행합니다. Xcode 설치나 소스 빌드가 필요하지 않습니다.
3. 이번 파일은 ad-hoc 서명이며 Apple Developer ID 서명·공증은 없습니다.
   첫 실행 시 macOS가 차단할 수 있습니다. 이 배포본을 신뢰하여 실행하기로
   선택한 경우 시스템 설정 > 개인정보 보호 및 보안에서 Apple 안내를 따르세요.
   https://support.apple.com/ko-kr/102445
4. 잠금 후 디스플레이 끄기를 사용하려면 손쉬운 사용 권한을 허용합니다.
   잠자기 금지 변경에는 macOS 관리자 인증이 필요할 수 있습니다.
5. 원하면 앱에서 로그인 시 실행을 켭니다.

업데이트 시 기존 앱을 종료한 뒤 같은 위치의 앱을 교체하세요.
ad-hoc 빌드가 변경되면 손쉬운 사용 권한에 앱을 다시 추가해야 할 수 있습니다.
